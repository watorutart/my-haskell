# Haskell学びメモ 20260702-2

- 畳み込み(fold)と呼ばれる便利な関数たちが用意されてる
  - 畳み込みを使うと、データ構造（例えばリスト）を単一の値にまとめることができる
    - → まさかとは思うけどこれ関手や自然変換だったりしないよな？
  - 畳み込み関数は2引数関数（2つの引数を取る関数。+やdivなど）と、畳み込みに用いる値（アキュムレータと呼ばれがち）の初期値
    - それに畳み込みリストを受け取る
    - アキュムレータという名前から察するにこれはTSでいうreduceみたいなものだな？
    - アキュムレータとリストの先頭or最後の要素を引数として、与えられた2引数関数を呼び出す
    - その結果の値が、新しいアキュムレータになる
    - 畳み込み関数は、新しいアキュムレータと新しく先頭（あるいは最後）になった要素を引数として再び2引数関数を呼び出し、新しいアキュムレータを作る

- foldlは「2引数関数」「アキュムレータ」「畳み込み対象のリスト」の3つを引数に取ることを型が教えてくれる
- これはリストを左側から順に畳み込んでいくので、左畳み込み（left fold)と呼ばれる
  - 最初のアキュムレータとリストの先頭要素に2引数関数が適用される

```
ghci> :t foldl
foldl :: Foldable t => (b -> a -> b) -> b -> t a -> b
```

- 畳み込みを使った場合と、簡潔に書いた場合。
  - `foldl (+) 0`はリストをとる関数なので引数のxsは省略できる模様
    - `foo a = bar b a`のような関数があった場合、カリー化のおかげで`foo = bar b`のように書き換えられる
- foldlってfold leftってことか

```
sum' :: (Num a) => [a] -> a
sum' xs = foldl (\acc x -> acc + x) 0 xs
----
sum' :: (Num a) => [a] -> a
sum' = foldl (+) 0
```

- `foldl :: Foldable t => (b -> a -> b) -> b -> t a -> b` の `t a` の意味がわからなかったので調べた
  - `a` … 中身の要素の型。TSのジェネリック `T` と同じ感覚
  - `t` … `Array`・`Map`・`Maybe` のような「容れ物」自体を抽象化した型変数
    - TSのジェネリクスは型（`Array<T>` の `T` など）しか変数にできないが、Haskellの `t` は `Array` や `Maybe` のような「型を作るもの」自体を変数にできる（→高階型 / higher-kinded types）
  - つまり `Foldable t => t a` は「`Array` でも `Map` でも `Maybe` でも、畳み込みができる容れ物ならなんでも入れていいよ、かつその中身は `a` 型だよ」という意味
  - → 詳細は `docs/glossary.md` の「高階型」参照

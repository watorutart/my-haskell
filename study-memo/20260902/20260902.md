# Haskell学びメモ 20260902

- 代数データ型を使えば列挙型をつくれる。そのためにEnumとBounded型クラスが便利
- 値コンストラクタがゼロ引数なのでEnum型クラスに属させられる
- Show, Readのインスタンスなので文字列にできるし、文字列から変換できる
- Eq, Ordのインスタンスなので等号・不等号が使える
- Boundedのインスタンスなので上限・下限を取れる
- Enumなので昨日・明日の曜日を知れるし、範囲指定でリストも作れる

```
ghci> Wednesday
Wednesday
ghci> show Wednesday
"Wednesday"
ghci> read "Saturday" :: Day
Saturday
ghci> Saturday == Sunday
False
ghci> Saturday == Saturday
True
ghci> Saturday > Friday
True
ghci> Monday `compare` Wednesday
LT
ghci> minBound :: Day
Monday
ghci> maxBound :: Day
Sunday
ghci> succ Mon
Monad      MonadFail  Monday     Monoid
ghci> succ Monday
Tuesday
ghci> pred Saturday
Friday
ghci> [Thursday .. Sunday]
[Thursday,Friday,Saturday,Sunday]
ghci> [minBound .. maxBound] :: [Day]
[Monday,Tuesday,Wednesday,Thursday,Friday,Saturday,Sunday]
```

 # Haskell学びメモ 20260809

- 人のデータ型を用意して、　インスタンス?を作成

```
data Person = Person String String Int Float String String
    deriving (Show)
----
ghci> let guy = Person "Buddy" "Finklestein" 43 184.2 "526-2928" "Chocolate"
ghci> guy
Person "Buddy" "Finklestein" 43 184.2 "526-2928" "Chocolate"
```

- 特定の情報を取り出すには関数が必要
- こんなのでもできるが、、
  - レコード構文でやった方が楽

```

firstName :: Person -> String
firstName (Person firstname _ _ _ _ _) = firstname

lastName :: Person -> String
lastName (Person _ lastname _ _ _ _) = lastname
```

- レコード構文でやった場合
  - フィールドの型名をスペース区切りで列挙 → 中括弧を使って{フィールド名 :: 型名}を書く
- 同じようにフィールドを取得できる

```
data Person = Person { firstName :: String
                     , lastName :: String
                     , age :: Int
                     , height :: Float
                     , phoneNumber :: String
                     , flavor :: String } deriving (Show)
----
ghci> firstName guy
"Buddy"
ghci> flavor guy
"Chocolate"
```

- 型を見ると関数になってるっぽい

```
ghci> :t firstName
firstName :: Person -> String
ghci> :t firstName
firstName :: Person -> String
```

- レコード構文で書けば順不同で指定してインスタンス生成可能
  - これはTSの関数とかでも似たようなことはできる。オブジェクト型を受け取るようにして名前指定で引数渡す。みたいな？
- インスタンスを作るのに色々指定する必要があるときはレコードが便利

```
data Car = Car { company :: String
               , model :: String
               , year :: Int
               } deriving (Show)
----
ghci> Car {company="Ford", model="Mustang", year=1967}
Car {company = "Ford", model = "Mustang", year = 1967}
```

-  memo：derivingは「導き出す」って意味がある模様

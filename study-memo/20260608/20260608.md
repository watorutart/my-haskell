# Haskell学びメモ 20260608

- whereキーワードを使って計算の中間結果に名前をつける
  - whereキーワードを使うことで条件式で繰り返す使うような値をwhereで定義しておけるみたい。これ欲しかった機能かも。好きかも。。
  - 複数もいけるみたい。ただし、whereの後の変数はインデント揃えてあげないといけない。（ブロックの範囲を正しく認識できずコンパイルエラーになる）
- whereで定義した変数のスコープはガードのみ。下記のようなプログラムはコンパイルエラーになる

```
greet :: String -> String
greet "Juan" = niceGreeting ++ " Juan!"
greet "Fernando" = niceGreeting ++ " Fernando!"
greet name = badGreeting ++ " " ++ name
    where niceGreeting = "Hello! So very nice to see you,"
          badGreeting = "Oh! Pfft. It's you."
```

- whereの束縛の中でもパターンマッチを使うことができる
  - （束縛ってなんだっけ...？）
  - なるほど、引数のfirstname/lastnameから先頭文字だけを抽出したって感じか
  - てか、これパターンマッチっていうんだっけ？

```
initials :: String -> String -> String
initials firstname lastname = [f] ++ ". " ++ [l] ++ "."
    where (f:_) = firstname
          (l:_) = lastname
```

- $：関数適用演算子
  - 普通の関数適用（2つのものの間に空白を置く）は非常に高い優先順位を持っている。が、$はもっとも低い優先順位を持っている。
  - 括弧の数を少なくしたいときにこれが役にたつ
  - `sum (map sort [1..130])`は`sum $ map sqrt [1..130]`にできる
  - `sqrt (3 + 4 + 9)`は`sqrt $ 3 + 4 + 9`にできる

```
($) :: (a -> b) -> a -> b
f $ x = f x
```

- こんな感じで括弧を省略できる

```
ghci> sum (filter (> 10) (map (*2) [2..10]))
80
ghci> sum $ filter (> 10) (map (*2) [2..10])
80
ghci> sum $ filter (> 10) $ map (*2) [2..10]
80
```

- 関数($ 3)がリストに対してmapされる。($ 3)HA関数を引数にとって3に適用する関数。従ってリスト中のすべての関数が3に適用される

```
ghci> map ($ 3) [(4+), (10*), (^2), sqrt]
[7.0,30.0,9.0,1.7320508075688772]
```

- 伏線: `foldl f z xs == last (scanl f z xs)` が成立する。scanlは「履歴を全部保存したfoldl」で、foldlは「その履歴の最後だけを覗き見たscanl」に過ぎない。この"履歴を持つ構造"と"そこから1点だけ取り出す操作"のペアは、後でmonad/comonadという概念を学んだときにまた同じ形で出てくる。

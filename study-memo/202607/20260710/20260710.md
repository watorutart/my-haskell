# Haskell学びメモ 20260711

- モジュール：いくつかの関数や型、型クラスなどを定義したファイル。それをエクスポートできる
  - Haskellのプログラムはモジュールの集合
  - → ちょっと前から出てた奴だな。GHCiでloadする時、複数のファイルをやるにはモジュールで分けなきゃみたいな奴だろ？
- エクスポート：モジュールの中のものを外の世界からも見えるように使えるようにすること
  - これは他でも一緒だな
- メリットも一緒、疎結合でできていいねと
- Haskellの標準ライブラリも複数のモジュールで分割してるよ
  - これまでの章で使ってきた全ての関数・型・型クラスはデフォルトでインポートされるPreludeというモジュールの一部
- モジュールのインポート：import {ModuleName}でできる。インポート構文は全ての関数定義よりも前に書く必要がある。
  - 複数のモジュールをインポートしたい場合はimport文を1行に1つずつ書く必要あり

- nub：リストから重複する要素を取り除く関数
- 探してる関数がどこにあるのか知りたい時はHoogle（http://www.haskell.org/hoogle/）を使うとよいでしょう。関数名、モジュール名、はては型シグネチャからも検索できる

```
import Data.List

numUniques :: (Eq a) => [a] -> Int
numUniques = length . nub
```

- GHCiからもモジュールは使える(現在はimport文も使える)

```
ghci> :m + Data.List Data.Map Data.Set
```

- 特定のものだけimportもできるし、特定のもの以外のimportもできる
- 名前の競合を避ける方法の1つとして、修飾付きインポートがある
  - これもTSと同じだな
- インポートしたものの参照には`.`が使われるが、`.`は関数合成演算子としても使われる。Haskellはどう区別してる？
  - → 自分の考え：スペースの有無では？
  - → 正解っぽい

```
-- 特定のものをimport
import Data.List (num, sort)
-- 特定のもの以外のimport
import Data.List hiding (nub)
-- 修飾付きインポートの例: filterを使う時
-- 使わない場合
import qualified Data.Map
Data.Map.filter ...
-- 使った場合
import qualified Data.Map as M
M.filter ...
```

# Haskell学びメモ 20260723

- 6.3.1ではlookupをした。キーに対応した値が欲しければ見つかるまで全ての要素を操作する必要がある
- はるかに高速な連想リストとUtil関数がData.Mapモジュールにある！
  - これからは「連想リストを使う」代わりに「Mapを使う」ということにする
  - Data.MapはPreludeやData.Listと競合する名前をエクスポートしているので、修飾付きインポートをする
- fromListで連想リストをMapに変換する
  - 元のリストに重複したキーがあった場合、後の方の要素が使われる

```
ghci> import qualified Data.Map as Map
ghci> Map.fromList [(3, "shoes"), (4, "trees"), (9, "bees")]
fromList [(3,"shoes"),(4,"trees"),(9,"bees")]
ghci> Map.fromList [("kima", "greggs"), ("jimmy", "mcnulty"), ("jay", "landsman")]
fromList [("jay","landsman"),("jimmy","mcnulty"),("kima","greggs")]
ghci> Map.fromList [("MS", 1), ("MS", 2), ("MS", 3)]
fromList [("MS",3)]
```

- fromListの型シグネチャ
  - 型kとaのペアのリストを受け取り、kをキー、aを値とするMapを返す
  - 普通のリストによる連想リストでは、キーは等値比較だけできれば良かったが(Eq型クラスに属する型であれば良かった)、Mapでは順序比較が必要なことに注意すること

```
ghci> :t Map.fromList
Map.fromList :: Ord k => [(k, a)] -> Map.Map k a
```

```
ghci> :t Map.lookup
Map.lookup :: Ord k => k -> Map.Map k a -> Maybe a
ghci> Map.lookup "betty" phoneBook
Just "555-2938"
ghci> Map.lookup "wendy" phoneBook
Just "939-8282"
ghci> Map.lookup "grace" phoneBook
Nothing
ghci> :t Map.insert
Map.insert :: Ord k => k -> a -> Map.Map k a -> Map.Map k a
ghci> Map.lookup "grace" phoneBook
Nothing
ghci> let newBook = Map.insert "grace" "341-9021" phoneBook
ghci> Map.lookup "grace" newBook
Just "341-9021"
ghci> :t Map.size
Map.size :: Map.Map k a -> Int
ghci> Map.size phoneBook
6
ghci> Map.size newBook
7
```

- Data.Mapのmapは、関数とMapを受け取り、その関数をMapの中の各値に適用

```
ghci> string2digits "948-9282"
[9,4,8,9,2,8,2]
ghci> let intBook = Map.map string2digits phoneBook
ghci> :t intBook
intBook :: Map.Map String [Int]
ghci> Map.lookup "betty" intBook
Just [5,5,5,2,9,3,8]
```

- 重複したキーがあるとfromListだとデータが失われる
- 代わりにfromListWithを使う
  - こいつは重複を削除しない。代わりに重複時にどうするかを決める関数を受け取る
  - fromListWithは既に存在するキーを見つけると与えられた結合関数にそれら競合する2つの値を渡し、得られた値で古い値を置き換える
    - 下記のaddの引数で渡してやってるっぽい

```
phoneBook =
    [("betty", "555-2938")
    ,("betty", "342-2492")
    ,("bonnie", "452-2928")
    ,("patsy", "493-2928")
    ,("patsy", "943-2929")
    ,("patsy", "827-9162")
    ,("lucille", "205-2928")
    ,("wendy", "939-8282")
    ,("penny", "853-2492")
    ,("penny", "555-2111")]

phoneBookToMap :: (Ord k) => [(k, String)] -> Map.Map k String
phoneBookToMap xs = Map.fromListWith add xs
    where add number1 number2 = number1 ++ ", " ++ number2
----
ghci> Map.lookup "patsy" $ phoneBookToMap phoneBook
Just "827-9162, 943-2929, 493-2928"
ghci> Map.lookup "wendy" $ phoneBookToMap phoneBook
Just "939-8282"
ghci> Map.lookup "betty" $ phoneBookToMap phoneBook
Just "342-2492, 555-2938"
```

- あらかじめ連想リストの値を単一要素のリストにしておけば電話番号を連携するのに++が使える

```
phoneBookToMap :: (Ord k) => [(k, a)] -> Map.Map k [a]
phoneBookToMap xs = Map.fromListWith (++) $ map (\(k, v) -> (k, [v])) xs
----
ghci> Map.lookup "patsy" $ phoneBookToMap phoneBook
Just ["827-9162","943-2929","493-2928"]
```
-- 番号の連想リストからMapを作ってそのキーに対する値の中の最大値を保持したい場合

```
ghci> Map.fromListWith max [(2,3), (2,5), (2,100), (3,29), (3,22), (3,11), (4,22), (4,15)]
fromList [(2,100),(3,29),(4,22)]
```

- 同じキーの値を足し合わせることも可能

```
ghci> Map.fromListWith (+) [(2,3), (2,5), (2,100), (3,29), (3,22), (3,11), (4,22), (4,15)]
fromList [(2,108),(3,62),(4,37)]
```

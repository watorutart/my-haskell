# Haskell学びメモ 20260724

- モジュールとエクスポートの話
- 幾何学オブジェクトの体積と面積を計算する小さいモジュールを作ろう！
- モジュール名とファイル名は一致させなきゃいけない模様
- モジュールを使うにはimport {モジュール名}をする。ただし、インポートするモジュールと同じフォルダになきゃダメ

----

- モジュールには階層構造を与えられる
- Geometryフォルダを作って3つのファイルを作る
- import Geometry.Sphereみたいな感じでインポートできる！
- 2つあるいはそれ以上のモジュールを操作したいなら修飾付きインポートを使う必要がある。同じ名前の関数をエクスポートしているので

```
import qualified Geometry.Sphere as Sphere
import qualified Geometry.Cuboid as Cuboid
import qualified Geometry.Cube as Cube
```

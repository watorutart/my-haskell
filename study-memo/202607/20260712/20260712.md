# Haskell学びメモ 20260712

- 干し草の山から針を探す
  - haystack(干し草の山)：検索対象のリスト
  - needle(針)：検索したいリスト
- Data.List.tails：tailsはリストを受け取り、そのリストに対してtail関数を繰り返し適用する

```
ghci> tails "party"
["party","arty","rty","ty","y",""]
```

- 文字列"party"から"art"を探そう！
  - まずはtails関数を使ってリストのtailを全て取得する。
  - 各tailを調べて"art"で始まるやつを探せば、探し当てたってこと
- Data.List.isPrefixOf：ある文字列が別の文字列から始まっているかどうかを調べる
  - 2つのリストを引数に取り、2つ目のリストが1つ目のリストで始まっているかどうかを教えてくれる

```
ghci> "hawaii" `isPrefixOf` "hawaii joe"
True
ghci> "haha" `isPrefixOf` "ha"
False
ghci> "ha" `isPrefixOf` "ha"
True
```

- haystackのtailにneedleから始まるものがあるか調べる
- Data.List.any：述語とリストを受け取り、要素のどれかが述語を満たすかどうかを返す

```
ghci> any (>4) [1,2,3]
False
ghci> any (=='F') "Frank Sobotka"
True
ghci> any (\x -> x > 5 && x < 10) [1,4,11]
False
```

- これらを組み合わせる

```
import Data.List

isIn :: (Eq a) => [a] -> [a] -> Bool
needle `isIn` haystack = any (needle `isPrefixOf`) (tails haystack)
---
ghci> "art" `isIn` "party"
True
ghci> [1,2] `isIn` [1,3,5]
False
```

- ここまでやっといてまさかのData.Listにすでにあるというオチ
- isInfixOf：干し草の山から針を探す関数

```
ghci> "art" `isInfixOf` "party"
True
ghci> [1,2] `isInfixOf` [1,3,5]
False
```

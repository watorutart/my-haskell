-  ポイントフリースタイル：ポイントを使わないで関数を定義するスタイル
  - ポイント：fn x = f (g x) のような関数定義に登場する一時変数xのこと
  - 良くわからんが一時変数を使わない関数のことかな

```
sum' :: (Num a) => [a] -> a
sum' xs = foldl (+) 0 xs
```

- イコールの両側とも右端がxs、関数はカリー化されているので、この両側のxsは省略できる
  - → これは前に出てきたη簡約だな？

```
-- 書き換え
sum' :: (Num a) => [a] -> a
sum' = foldl (+) 0
```

- fnをポイントフリーにすると？
  - → cos (max 50)がNGになる
  - こういうときは関数合成の出番
  - ただし、関数が複雑になりすぎるとポイントフリースタイルで可読性が低くなることもある。あんまり関数合成のチェインは長くしないようにしよう
    - → letを使って途中の結果にラベルを与えて分解すると良い

```
fn x = ceiling (negate (tan (cos (max 50 x))))
-- NG例 cos (max 50)は関数のcosを取ってしまう
fn = ceiling (negate (tan (cos (max 50))))
-- → 代わりに関数合成をやる
fn = ceiling . negate . tan . cos . max 50
```

- なぜ `sum' xs = foldl (+) 0 xs` の両辺から `xs` を省略できるのか？
  - `foldl (+) 0` の時点で、すでに「残り1つのリスト引数を受け取れば計算できる関数」が完成している(部分適用)
  - `sum' xs = foldl (+) 0 xs` は「xsを受け取ったら、foldl (+) 0にそのままxsを渡す」と言っているだけ → どんなxsでも両辺が一致するので、関数自体(sum'とfoldl (+) 0)も同じもの
  - → だから `sum' = foldl (+) 0` と書ける(イータ簡約)

- 「部分適用関数」というのは特別な種類の関数ではない
  - Haskellに「多引数関数」という実体はなく、全て1引数関数の連鎖
    - `foldl :: (b -> a -> b) -> b -> t a -> b` は実際には `(b -> a -> b) -> (b -> (t a -> b))` という1引数関数が1引数関数を返す連鎖
  - 「部分適用」とは、この連鎖の途中(全部より少ない数)まで引数を渡して止まっている状態のこと
  - 元の関数(`foldl`)も部分適用の結果(`foldl (+) 0`)も、構造上はどちらも同じ「1引数関数」
  - → カリー化されているからこそ、多引数に見える関数へ一部だけ引数を渡す(部分適用する)ことができる

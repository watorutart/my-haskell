# Haskell学びメモ 20260726

- 自分でデータ型を作る
- 自作のデータ型を作る方法の1つはdataキーワードを使うこと
- dataキーワードを使うと、新しいデータ型を定義する構文になる
  - 等号の前の部分は型の名前
  - 等号の後の部分は値コンストラクタ
    - |はまたはの意味。取りうる値の種類を指定している

```
data Bool = False | True
```

- Intのはこんな感じ
- ※途中の数が省略されてるのもあり、実際はこんな定義ではない

```
data Int = -2147483648 | -2147483647 | ... | -1 | 0 | 1 | 2 | ... | 2147483647
```

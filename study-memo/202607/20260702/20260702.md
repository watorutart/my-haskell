# Haskell学びメモ 20260702

- ラムダ式：1回だけ必要な関数を作るときに使う無名関数
  - 通常ラムダ式は高階関数に渡す関数を作るためだけに使われる
  - ラムダ式を宣言するにはバックスラッシュを書いて、関数の引数をスペース区切りで書く。->、最後に関数の本体を書く
  - `\`はラムダにギリ見えるからこうしてるらしい
  - 普通ラムダ式は括弧で囲む

```
numLongChains :: Int
numLongChains = length (filter (\xs -> length xs > 15)
    (map chain [1..100]))
```

- カリー化・部分適用がわかっていないと不要にラムダ式を使いがち
  - 例えば下記

```
ghci> map (+3) [1,6,3,2]
[4,9,6,5]
ghci> map (\x -> x + 3) [1,6,3,2]
[4,9,6,5]
```

- ラムダ式も任意の数の引数を取ることができます。

```
ghci> zipWith (\a b -> (a * 30 + 3) / b) [5,4,3,2,1] [1,2,3,4,5]
[153.0,61.5,31.0,15.75,6.6]
```

- ラムダ式でもパターンマッチができる
  - 唯一異なるのは1つの引数に対して複数のパターンを定義できないところ
    - 同じ引数に対して[]と(x:xs)のパターンを作って合致する方を選択する、といったもの
    - どゆこと？
  - 注意：ラムダ式でパターンマッチが失敗したらランタイムエラーになる

```
ghci> map (\(a,b) -> a + b) [(1,2),(3,5),(6,3),(2,6),(2,5)]
[3,8,9,8,7]
```

- 関数はデフォルトでカリー化されてるので下記は等価
  - 可読性は前者の方が圧倒的

```
ghci> addThree 1 2 3
6
ghci> addThree' 1 2 3
6
```

- カリー化の方が便利な時もある
  - `flip' f x y = f y x`ともかけるがラムダ式で書いた方が新しい関数を生成するflipの使い方をよく表している
  - なるほどラムダ式の`\`はTSでいう`() => { /* ここにロジック */ }`みたいなもんか

```
flip' :: (a -> b -> c) -> b -> a -> c
flip' f = \x y -> f y x
----
ghci> zipWith (flip (++)) ["love you", "love me"] ["i ", "you "]
["i love you","you love me"]
ghci> map (flip subtract 20) [1,2,3,4]
[19,18,17,16]
```

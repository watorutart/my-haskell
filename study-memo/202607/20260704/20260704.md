# Haskell学びメモ 20260704

- foldlとfoldrで`b -> a -> b`か`a -> b -> b`なのかで違うっぽい

```
ghci> :t foldl
foldl :: Foldable t => (b -> a -> b) -> b -> t a -> b
ghci> :t foldr
foldr :: Foldable t => (a -> b -> b) -> b -> t a -> b
```

- 前者が右畳み込み、後者が左畳み込み
  - しかし、`++`関数は`:`よりも遅い
- 右畳み込みと左畳み込みの違いは、右は無限リストに対しても動作する。左はNG
  - そうか遅延評価なものの、無限リストは最後尾がわからんからか

```
map' :: (a -> b) -> [a] -> [b]
map' f xs = foldr (\x acc -> f x : acc) [] xs
----
map' :: (a -> b) -> [a] -> [b]
map' f xs = foldr (\acc x -> acc ++ [f x]) [] xs
```

- elemを右畳み込み
  - 初期値Falseで引数と要素が一致したらTrueにする

```
elem' :: (Eq a) => a -> [a] -> Bool
elem' y ys = foldr (\x acc -> if x == y then True else acc) False ys
```

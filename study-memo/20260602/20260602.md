# Haskell学びメモ 20260602

- タプルでもパターンマッチが使える
- 下記addVectorsで全てに合致するパターンになっている

```
addVectors :: (Double, Double) -> (Double, Double) -> (Double, Double)
addVectors (x1, y1) (x2, y2) = (x1 + x2, y1 + y2)
```

- トリプルの要素の分解をパターンマッチングを使ってやる
- _はリスト内包表記の時と同じ意味。どうでも良い値なので使い捨ての変数を表すために使用

```
first :: (a,b,c) -> a
first (x, _, _) = x

second :: (a,b,c) -> b
second (_, y, _) = y

third :: (a,b,c) -> c
third (_, _, z) = z
```

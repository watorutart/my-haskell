# Haskell学びメモ 20260619

- 中置関数に対しても、セクションという機能を使って部分適用することができる
  - 片側だけに値を置いて括弧で囲むだけ
- セクションで唯一気をつけなければならないのは、負の数、マイナス演算子を同時に使うとき
  - (-4)は4を引く関数ではなくマイナス4を意味することになっている
  - → その場合は(subtract 4)のようにする必要がある

```
divideByTen :: (Floating a) => a -> a
divideByTen = (/10)
---
ghci> divideByTen 200
20.0
ghci> 200 /10
20.0
ghci> (/10) 200
20.0
```

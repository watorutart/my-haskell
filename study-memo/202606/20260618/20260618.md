# Haskell学びメモ 20260618

- 高階関数：引数として関数を取ったり返り値として関数を返したりできる関数
- Haskellの全ての関数は引数を1つだけ取ることになっている。
  - 複数の引数を取る関数を定義してこれたのはカリー化された関数だったから。
    - カリー化関数は複数の引数を取る代わりに、常にちょうど1つの引数を取る引数を取る関数
    - カリー化：「1引数しか受け取れない」という制約を守りつつ複数引数を扱うために、1個目を受け取る → 残りを処理する関数を返す → その関数が2個目を受け取る → … という連鎖にする
      - 「処理する」という部分、厳密にいうと 最後の引数が来るまで実際の計算（x + y）は始まりません。途中の段階でやっているのは「引数を覚えて、次を待つ関数を返す」だけです。
- 例としてmaxを見る
  - max :: (Ord a) => a -> (a -> a)　ともかける

```
ghci> max 4 5
5
ghci> (max 4) 5
5
ghci> :t max
max :: Ord a => a -> a -> a
```

- これの何が嬉しいの？：関数を本来より少ない引数で呼び出したときに部分適用された関数が得られる！
  - 部分適用された関数は残りの変数を引数として取る関数
  - max 4とすると1引数の関数を返す。部分適用を使うと、関数をその場でお手軽に作り出して、それを他の関数に渡せる
- 関数は、何か材料を受け取って何かを作り出す小さな工場。
  - 例：multiThreeに数3を与えたら、数ではなくてちょっと小さくなった別の工場が出てきた。そのちょっと小さな工場は、数5を受け取り、また別の工場を作り出します。3つ目の工場は数9を受け取り最終結果の135を出す。
  - multiThreeの関数の型は multiThree :: Int -> (Int -> (Int -> Int)) ともかける
  - 

```
multiThree :: Int -> Int -> Int -> Int
multiThree x y z = x * y * z
```

- 本来より少ない引数で関数を呼び出すことによって新しい関数を作る例

```
ghci> let multiTwoWithNine = multiThree 9
ghci> multiTwoWithNine 2 3
54
```

- compare 100が何を返すか？数を引数に取り、100と比較する関数である
- compareは(Ord a) => a -> (a -> Ordering)という型を持ちます。
- これを100に適用すると、「数を引数に取りOrderingを返す関数」が得られます。

```
compareWithHundred :: Int -> Ordering
compareWithHundred x = compare 100 x
----
ghci> compareWithHundred 99
GT
ghci> :t compareWithHundred
compareWithHundred :: Int -> Ordering
```

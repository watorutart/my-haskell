# Haskell学びメモ 20260612

- case式：変数の指定した値に対するコードブロックを評価できる
  - switchのcaseみたいに特定の値のチェックだけ使える感じかな？
  - → コード中のどこでもパターンマッチが使える構文。なるほど
  - しかしHaskellは一歩先をいく。caseも式である。評価の分岐だけじゃなくパターンマッチも使える
    - 関数の引数に対するパターンマッチと似ているとのこと
    - → なんとcase式の構文糖衣になってる
  - どうもcaseのof以降はインデント合わせないといけないっぽい
  - 式に合致した最初のパターンが使われる。見つからなかったらランタイムエラー
  - 引数のパターンマッチが使えるのは関数を定義するだけだが、case式はどこでも使える

```
case expression of pattern -> result
                pattern -> result
                pattern -> result
```

- 以下、どっちも同じ意味

```
describeList ls = "The list is "
    ++ case ls of [] -> "empty."
                  [x] -> "a singleton list."
                  xs -> "a longer list."

-- 上と同じ意味
describeList ls = "The list is " ++ what ls
    where what [] = "empty."
          what [x] = "a singleton list."
          what xs = "a longer list."
```

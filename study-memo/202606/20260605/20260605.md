# Haskell学びメモ 20260605

- asパターン：値をパターンに分解しつつ、パターンマッチの対象になった値自体も参照したいときに使う
  - 使う時は普通のパターンの前に名前と@を追加する
  - → どういうこった
  - なるほど、asパターン名＋実際のパターンがどういうものかを書くのね
- xで値をパターンに分解して、xsで元のリスト全体にアクセスすることもできる

```
firstLetter :: String -> String
firstLetter "" = "Empty string, whoops!"
firstLetter all@(x:xs) = "The first letter of " ++ all ++ " is " ++ [x]
----
ghci> firstLetter "Dracula"
"The first letter of Dracula is D"
```

- 関数を定義するとき、引数の構造で場合分けする時はパターンを使う
- 引数の値が満たす性質で場合分けする時には、ガードを使う
  - ifとガードは似ているものの、完全に同じではないっぽい
  - ガードの方がifより可読性が高いっぽい
  - ガードにはパイプ文字とそれにつづく真理値式、さらにその式がTrueに評価された時に使われる関数の本体が続く
    - 式がFalseなら、次のガードの評価に移る
      - → 基本2つ目以降はelse ifっぽいな？
    - ガードは最低でも1つのスペースでインデントする必要がある。スペース4つのインデントがおすすめっぽい
      - → へー、インデント消したらエラー出たわ。Python的な思想も含んでるんだな
    - otherwiseがelseやdefaultに当たるもの
- NOTE: ガード節はイコールは不要。パイプを使う（関数名の後にイコールをつけがちなので注意。構文エラーになる）

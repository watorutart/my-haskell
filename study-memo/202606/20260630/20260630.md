```
ghci> map (+3) [1,5,3,1,6]
[4,8,6,4,9]

[[1,4],[9,16,25,36],[49,64]]
```

- filter：述語とリストを受け取り、そのリストから述語を満たすやつだけ返す。これもTSと一緒
  - 若干わかりづらいがpが述語の関数でxがpを満たせばxをリストの先頭に置いて残りのxsを同様に処理、って感じだな

```
filter' :: (a -> Bool) -> [a] -> [a]
filter _ [] = []
filter p (x:xs)
    | p x = x : filter p xs
    | otherwise = filter p xs
```

- どういう時にリスト内包表記とmap,filterを使い分けるか、ルールはない模様。
  - 読みやすい方で良いとのこと。
- あれかも、いっぱいフィルター条件ある時はリスト内包表記のが読みやすいかも

```
ghci> filter (<15) (filter even [1..20])
[2,4,6,8,10,12,14]
ghci> [x | x <- [1..20], x < 15, even x]
[2,4,6,8,10,12,14]
```

quicksort :: (Ord a) => [a] -> [a]
quicksort [] = []
quicksort (x:xs) =
    let smallerOrEqual = filter (<= x) xs
        larger = filter (> x) xs
    in quicksort smallerOrEqual ++ [x] ++ quicksort larger

quicksort :: (Ord a) => [a] -> [a]
quicksort [] = []
quicksort (x:xs) =
    let smallerOrEqual = [a | a <- xs, a <= x]

# Haskell学びメモ 20260626

- 高階関数っぽい。なんだ高階実演って高階関数の実演か？
- ->は右結合なので、これまでの例では関数の型を宣言するときに括弧は必要なかった
  - → これは`a -> a -> a`だとしたらaを関数(a -> a)に渡しているからと理解

```
applyTwice :: (a -> a) -> a -> a
applyTwice f x = f (f x)
```

- 実演

```
ghci> applyTwice (++ " HAHA") "HEY"
"HEY HAHA HAHA"
ghci> applyTwice ("HAHA " ++) "HEY"
"HAHA HAHA HEY"
ghci> applyTwice (3:) [1]
[3,3,1]
```

- ghciで2ファイルをロードしたい場合
  - :lだと1ファイルをロードしてそれまでのはリセットされる
  - 2ファイル目以降をロードするには`:add`をする必要がある
- デフォルトはMainモジュールになってる
  - ファイルに何も書かない場合：
    - 自動的に module Main where が省略されているとみなされます（デフォルト）。
  - ファイルに明記した場合：
    - module Memo20260626 where のように書くことで、デフォルトの Main から自分だけの独立したパッケージに引っ越しができます。

```
ghci> applyTwice (multiThree 2 2) 9

<interactive>:20:1: error: [GHC-88464]
    Variable not in scope: applyTwice :: (Int -> Int) -> t0 -> t

ghci> :add study-memo/20260618/20260618.hs

    module ‘main:Main’ is defined in multiple files: study-memo/20260618/20260618.hs
                                                     study-memo/20260626/20260626.hs
Failed, one module loaded.

----
<!-- 20260626.hsに下記 -->
module Memo20260626 where
----

ghci> :add study-memo/20260618/20260618.hs
```

- 部分適用そんなに使うか？と思ったけど、どうもmap,filterでよく使うみたい
  - その時にロジックだけで書けるのが利点っぽい

```
-- 部分適用なしだと、わざわざ関数を作る必要がある
map (\x -> x * 2) [1,2,3]

-- 部分適用があれば一発
map (*2) [1,2,3]

-- 「10より大きい要素だけ残す」
filter (>10) [5, 12, 8, 20]   -- [12, 20]

-- 部分適用なしだと
filter (\x -> x > 10) [5, 12, 8, 20]
```

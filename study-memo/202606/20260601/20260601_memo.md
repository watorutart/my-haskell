# Haskell学びメモ 20260601

- パターンマッチ：ある種のデータが従うべきパターンを指定し、そのパターンに従ってデータを分解するために使う
- パターンに具体的な値でなく小文字から始まる名前（x, y, myNumber）を書くと、任意の値に合致するようになる。このパターンは与えられた値に常に合致し、その値をパターンに使った名前で参照できるようになる。
  - → 何言ってんだこいつ
  - おそらく早期リターン的に任意の値が何かが決まるのかな？先に具体的な値＝7を設定しておけば、そのあとのxは7以外になる？
  - → そうっぽい。で、switch文より強いらしい。。
- 再帰的に定義も可能
- パターン作る時は全てに合致するパターンを最後に入れておくべき
  - いわゆるdefaultは必須っぽい（ランタイムでエラーになる）
  - `-fwarn-incomplete-patterns`で警告してもらえる

- .hsファイルの先頭に`{-# OPTIONS -Wall -Werror #-}`をつけておくと警告を出してもらえる

## リスト内包表記の読み方（重要メモ）

- `[a | a <- xs, a <= x]` は **map ではなく filter** だった！
- 内包表記は `[ 変換 | 取り出し , 条件 ]` の3パーツでできてる
  - `a <- xs` … xsから要素aを取り出す（ループ）
  - `, a <= x` … 条件 → **filter**
  - 先頭の `a` … 取り出した値の変換 → **map**（今回は変換なしなので実質filterだけ）
- TypeScriptで書くとこう:

```typescript
const smallerOrEqual = xs.filter(a => a <= x);  // [a | a <- xs, a <= x]
const larger         = xs.filter(a => a > x);   // [a | a <- xs, a > x]
```

- もし先頭が `a * 2` なら filter してから map:
  - `[a * 2 | a <- xs, a <= x]` → `xs.filter(a => a <= x).map(a => a * 2)`
- quicksort全体をTypeScript風に書くと（`++` はスプレッド `[...]` に対応）:

```typescript
function quicksort(arr: number[]): number[] {
  if (arr.length === 0) return [];
  const [x, ...xs] = arr;                        // x:xs の分解
  const smallerOrEqual = xs.filter(a => a <= x);
  const larger         = xs.filter(a => a > x);
  return [...quicksort(smallerOrEqual), x, ...quicksort(larger)];
}
```

→ ポイント: **内包表記の「先頭の式」が map、「,のあとの条件」が filter**

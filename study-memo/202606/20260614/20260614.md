# Haskell学びメモ 20260614

- replicateを再帰で実装しよう！
  - replicateはIntと値をとり、複製という名の通り、その値を指定された数だけ繰り返したリストを返す
  - 基底部は0以下なら空リスト、それ以外ならxとxを(n-1)回繰り返したリストをtailに構築したリスト
  - 下記の通り。負のケースに対応するためにパターンじゃなくガードを使ってる模様

```
replicate' :: Int -> a -> [a]
replicate' n x
    | n <= 0 = []
    | otherwise = x : replicate' (n-1) x
```

- takeを実装
  - takeは指定されたリストから指定された数の要素を返す
  - 下記が基底部
    - リストから0よりも少ない要素を取り出そうとした場合には空のリストを返す
    - 空のリストから何かを取り出そうとした場合にも空のリストを返す
  - 3つ目のパターンは、リストをheadとtailに分解する。リストからn要素取り出したものは、xを1つ目の要素にしてxsからn-1要素を取り出したリストを残りの要素にしたリストと同じである、と定義している。

```
take' :: Int -> [a] -> [a]
take' n _
    | n <= 0 = []
take' _ [] = []
take' n (x:xs) = x : take' (n-1) xs
```

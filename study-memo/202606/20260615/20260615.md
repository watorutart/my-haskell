# Haskell学びメモ 20260615

- reverse関数：同じ要素で逆順のリストを返す関数
- 基底部は空リスト
- 残りの部分はheadとtailに分解すれば、tailを逆順にして後ろにheadをくっつけたものが逆順のリストになる

```
reverse' :: [a] -> [a]
reverse' [] = []
reverse' (x:xs) = reverse' xs ++ [x]
```

- repeatは要素を受け取りその要素から無限リストを作る関数
- repeatの評価は終了しない。take 5 (repeat 3)は5つの3からなるリストに評価される。
- ちなこれは基底部のない再帰を利用して無限リストを作る良い例。途中で切らないとダメよ

```
repeat' :: a -> [a]
repeat' x = x : repeat' x
```

- zip：2つのリストを引数に取り、これらをzipして（綴じ合わせて）返す。`zip [1,2,3] [7,8]`は[(1,7), (2,8)]を返すやーつ
- 空のリストをzipに渡すと空のリストになる。これが基底部
  - ただし、zipは2つの引数を取るので基底部は2つになる

```
zip' :: [a] -> [b] -> [(a, b)]
zip' _ [] = []
zip' [] _ = []
zip' (x:xs) (y:ys) = (x,y) : zip' xs ys
```

- elem：値とリストを受け取り、その値がリストに含まれるかを調べる。
- これも空のリストが基底部
- 一般のケースでは探したい値が先頭にあるかも。そうじゃない場合はtailにあるか調べる必要がある

```
elem' :: (Eq a) => a -> [a] -> Bool
elem' a [] = False
elem' a (x:xs)
    | a == x = True
    | otherwise = a `elem'` xs
```

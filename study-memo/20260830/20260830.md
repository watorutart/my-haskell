- ReadはShowの逆をする型クラスとのこと
  - つまり文字列を入力してPersonのインスタンス？を生成できるってこと？
    - → そうっぽい
  - 型注釈してあげればその型にできるよ
  - 型推論も効くよ
- 多相型も読み取れるけど、どの型が欲しいかHaskellが推論できるだけの情報を与える必要があるよ
  - `read "Just 3" :: Maybe a`だと何型でreadすればいいかわかんないよ。`read "Just 3" :: Int`ならできるよ
  - → 推測：readは値として確定するので文字列として多相型は入れられるけど、何かに型は確定させてねってことだと考えた

```
ghci> mikeD = Person {firstName = "Michael", lastName = "Diamond", age = 43}
ghci> mysteryDude = "Person { firstName = \"Michael\"" ++ ", lastName = \"Diamond\"" ++ ", age = 43}"
ghci> read mysteryDude :: Person
Person {firstName = "Michael", lastName = "Diamond", age = 43}
ghci> read mysteryDude == mikeD
True
ghci> read "Just 3" :: Maybe a
```

## Eq型クラス

- Eqは等値性をテストできる型に使われる
- Eqのインスタンスが実装すべきは==と/=
- 関数の型変数にEqクラスの制約が付いていたら、その関数の定義のどこかで == か /=が使われているということ
- 型が関数を実装しているとは、その関数がその特定の型に対して使われたときに、どういう振る舞いをするか定義するということ
  - → どゆこと？？

```
ghci> 5 == 5
True
ghci> 5 /= 5
False
ghci> 'a' == 'a'
True
ghci> "Ho Ho" == "Ho Ho"
True
ghci> 3.432 == 3.432
True
```

## Ord型クラス

- Ordは何らかの順序をつけられる型のための型クラス
- 今まで見てきた型は、関数は除いてすべてOrdのインスタンス。
- Ordは標準の大小比較関数、>, <, >=, <=をサポートする。
- compare関数はOrdのインスタンスの型の引数を2つ取り、Orderingを返す。
  - OrderingはGT, LTまたはEQのいずれかの値を取る型
  - それぞれ「より大きい」、「より小さい」、「等しい」を意味する

```
ghci> :t (>)
(>) :: Ord a => a -> a -> Bool
ghci> "Abrakagabra" < "Zebra"
True
ghci> "Abrakagabra" `compare` "Zebra"
LT
ghci> 5 >= 2
True
ghci> 5 `compare` 3
GT
ghci> 'b' > 'a'
True
```

## Show型クラス

- Show型クラスのインスタンスになっていれば文字列として表現できる
- 今まで見てきた型は関数を除けばすべてShowのインスタンス
- この型クラスのインスタンスに対する操作で一番よく使うのはshowで、これは指定した値を文字列として表示する関数

```
ghci> show 3
"3"
ghci> show 5.334
"5.334"
ghci> show True
"True"
```

## Read型クラス

- ReadはShowと対をなす型クラス
- 同様に今まで見てきたすべての型はこの型のインスタンス
- read関数は文字列を受け取り、Readのインスタンスの型の値を返す
- なんだこれ、勝手に文字列を型推論して計算処理してくれんのか。便利そう


```
ghci> read "True" || False
True
ghci> read "8.2" + 3.8
12.0
ghci> read "5" - 2
3
ghci> read "[1,2,3,4]" ++ [3]
[1,2,3,4,3]
```

- と思ったら、NGパターン出てきた
- readの推論は結果の値に何かしらの手が加えられていたからの模様
- Stringは[Char]の別名。

```
ghci> read "4"
*** Exception: Prelude.read: no parse

ghci> :t read
read :: Read a => String -> a
```

- この問題を解決するために型注釈を使う。TSのいつものやつ
- コンパイラはほとんどの式の型を自力で推論可能
  - 無理な時はこっちから教えてやる必要がある
- 型注釈は最低限でOK。例えばリストは同じ型制限あるので、同じリスト内で型が確定してれば他は不要

```
ghci> read "5" :: Int
5
ghci> read "5" :: Float
5.0
ghci> (read "5" :: Float) * 4
20.0
ghci> read "[1,2,3,4]" :: [Int]
[1,2,3,4]
ghci> read "(3, 'a')" :: (Int, Char)
(3,'a')
ghci> [read "True", False, True, False]
[True,False,True,False]
```

## Enum型クラス

- Enum型クラスはいつもの
- 利点：その値をレンジの中で使えること。
- Enumのインスタンスの型は後者関数succと前者関数predも定義されます。
- Enumのインスタンス：(), Bool, Char, Ordering, Int, Float, Double
- LT→EQ→GTってなるのはなぜ？？

  - LT：未満、EQ：等しい、GT：超過

```
ghci> [LT .. GT]
[LT,EQ,GT]
ghci> [3 .. 5]
[3,4,5]
ghci> succ 'B'
'C'
```

## Bounded型クラス

- Bounded型クラスのインスタンスは上限と下限を持ち、minBound, maxBound関数で調べられる
- タプルのすべての構成要素がBoundedのインスタンスなら、そのタプル自身もBoundedになる

```
ghci> minBound :: Int
-9223372036854775808
ghci> maxBound :: Char
'\1114111'
ghci> maxBound :: Bool
True
ghci> minBound :: Bool
False
ghci> maxBound :: (Bool, Int, Char)
(True,9223372036854775807,'\1114111')
```

リストから要素を取り出す。
[x <- [1, 10]]は取り出した各要素の値をxが受け取る。別表現でxに束縛しているという。
縦棒(|)より前の部分はリスト内包表記の出力。

```
[x*2 | x <- [1..10]]
```

条件(述語)を追加する。＝フィルタする。

```
ghci> [x*2 | x <- [1..10], x*2 >= 12]
[12,14,16,18,20]
ghci> [x | x <- [50..100], x `mod` 7 == 3]
[52,59,66,73,80,87,94]
```

リストを含むリストを操作する場合に入れ子になったリスト内包表記が作れる。

> 可読性のためにリスト内包表記を複数行に分けることもできます。
> ＭｉｒａｎＬｉｐｏｖａｃａ. すごいHaskellたのしく学ぼう！ (p. 40). (Function). Kindle Edition. 

```
ghci> let xxs = [[1,3,5,2,3,1,2,4,5],[1,2,3,4,5,6,7,8,9],[1,2,4,2,1,6,3,1,3,2,3,6]]
ghci> [[x | x <- xs, even x ] | xs <- xxs]
[[2,2,4],[2,4,6,8],[2,4,2,6,2,6]]
```

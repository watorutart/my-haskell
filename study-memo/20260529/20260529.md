# Haskell学びメモ 20260529

- Intは有界＝最小値/最大値がある
- Integerは有界ではない。え？IntとIntegerで違いあんの？
- Floatは単精度浮動小数点数
- Doubleは倍精度浮動小数点数
- Boolは真理値。True/False
- CharはUnicode文字。シングルクオートで括る
- タプルは型だけど要素の数とそれぞれの型によって決まる。空のタプル()も型、この型はただ1つの値のみを持つ

```
ghci> factorial 50
30414093201713378043612608166064768844377641568960512000000000000
ghci> circumference 4.0
25.132742
ghci> circumference' 4.0
25.132741228718345
```

factorialをIntegerからIntに変えて実行してみた

```
ghci> factorial' 50
-3258495067890909184
```

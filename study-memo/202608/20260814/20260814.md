# Haskell学びメモ 20260814

- Vectorは3要素あるけど1つの座標決まればいいので型引数は1つだけで良い
- 型クラス制約は関数側だけにあれば良い
  - データ宣言にNumつけても関数型のNumを省くことはできないので

```
data Vector a = Vector a a a deriving (Show)

vplus :: (Num a) => Vector a -> Vector a -> Vector a
(Vector i j k) `vplus` (Vector l m n) = Vector (i+l) (j+m) (k+n)

dotProd :: (Num a) => Vector a -> Vector a -> a
(Vector i j k) `dotProd` (Vector l m n) = i*l + j*m + k*n

vmult :: (Num a) => Vector a -> a -> Vector a
(Vector i j k) `vmult` m = Vector (i*m) (j*m) (k*m)
```

- Eq型クラスは「等値性テストができる物」という振る舞いを定義しているものだった
  - 便利なのは`==`と`/=`という関数があるから
- Haskellの型クラスは他言語の「クラス」とは別の話の模様、紛らわしいとおっしゃってる
  - 他言語でいうクラスはブループリントのこと
  - Haskellではデータを作る道具ではない。
    - まずデータ型を作り、それから「このデータに何ができるか？」を考える
    - 等値性をテストできるならEq型クラスのインスタンスにする
    - 大小比較するならOrd型クラスのインスタンスにする
- Haskellは特定の型クラスのインスタンス宣言を自動導出（derive）する能力を備えている
  - 自動導出可能なもの：Eq, Ord, Enum, Bounded, Show, Read
    - Boundedとかはなんだっけ。。
  - 自作のデータ型を作るとき、derivingキーワードを使えばHaskellが型クラスの文脈での振る舞いを自動導出してくれる

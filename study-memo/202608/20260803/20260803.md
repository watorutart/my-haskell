# Haskell学びメモ 20260803

- 以下はこんな意味
  - Circle値コンストラクタに浮動小数を受け取るフィールドが3つある
    - 最初の2つは円の中心の座標
    - 3つ目は円の半径
  - Rectangle値コンストラクタには浮動小数を受けるフィールドが4つある
    - 最初の2つは左下の角、後の2つは右上の角の座標を表す
    - 後の2つは右上の角の座標を表す
- 値コンストラクタは最終的にそのデータ型の値を返す関数

```
data Shape = Circle Float Float Float | Rectangle Float Float Float Float
```

- 型シグネチャはこんな感じ
  - へー値コンストラクタって言ってるけど、実態は関数なんだ
  - Shape型を返すのね

```
ghci> :t Circle
Circle :: Float -> Float -> Float -> Shape
ghci> :t Rectangle
Rectangle :: Float -> Float -> Float -> Float -> Shape
```

- 型宣言はShapeを受け取ってFloatを返す関数
  - しかしここにCircle -> Floatなんてのは書けない
  - Circleは型ではないので。確かに実態は関数だからか
- そしてコンストラクタはパターンマッチも使えるとのこと
  - フィールドがある値コンストラクタでパターンマッチをしたい場合、まず値コンストラクタ名を書き、それからフィールドを名前に束縛する。
  - 円の場合は半径しか必要じゃないので_で捨ててる

```
area :: Shape -> Float
area (Circle _ _ r) = pi * r ^ 2
area (Rectangle x1 y1 x2 y2) = (abs $ x2 - x1) * (abs $ y2 - y1)
```

- areaは動くけど、Circleは失敗する
  - これはCircleにデータ型を文字列にして表示する方法を（まだ）知らないから

```
ghci> area $ Circle 10 20 10
314.15927
ghci> area $ Rectangle 0 0 100 100
10000.0
ghci> Circle 10 20 5

<interactive>:7:1: error: [GHC-39999]
    • No instance for ‘Show Shape’ arising from a use of ‘print’
    • In a stmt of an interactive GHCi command: print it
```

- Circleを表示するには`deriving Show`のおまじないを書く
  - これをやるとHaskellが自動的にこの型をShow型クラスのインスタンスにしてくれる

```
data Shape = Circle Float Float Float | Rectangle Float Float Float Float
    deriving (Show)
----
ghci> Circle 10 20 5
Circle 10.0 20.0 5.0
ghci> Rectangle 50 230 60 90
Rectangle 50.0 230.0 60.0 90.0
```

- 値コンストラクタは関数だから、mapや部分適用ができる
- 以下は半径だけ違う同心円のリストを作る

```
ghci> map (Circle 10 20) [4,5,6,6]
[Circle 10.0 20.0 4.0,Circle 10.0 20.0 5.0,Circle 10.0 20.0 6.0,Circle 10.0 20.0 6.0]
```

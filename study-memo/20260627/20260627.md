# Haskell学びメモ 20260628

- flip：関数を引数にとり、元の関数と似ているけど最初の2つの引数が入れ替わった関数を返す
  - 型宣言から「a型とb型の値を引数に取る関数」を引数にとり、「b型とa型の値を引数に取る関数」を返す
  - なお関数はデフォルトでカリー化されてるので2つ目の括弧は不要
    - へーそうか。言われてみればだけど可読性的には合った方が良いな

```
flip' :: (a -> b -> c) -> (b -> a -> c)
flip' f = g
    where g x y = f y x
```

- `(a -> b -> c) -> (b -> (a -> c))`、`(a -> b -> c) -> b -> a -> c`とも書ける

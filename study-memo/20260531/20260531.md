## Floating型クラス

- Floating型クラスにはFloatとDoubleが含まれる
- 引数と返り値がFloating型クラスのインスタンスである関数は、その結果を浮動小数点数で表現できないと意味のある計算ができない。sin, cos, sqrtなど

## Integral型クラス

- Numは全ての実数に対して、Integralは整数（全体）のみが含まれる。つまりIntとInteger
- fromIntegralって関数が便利
- fromIntegralの型シグネチャに複数の型クラス制約がある。複数の型クラス制約を書くときは、間まで区切って括弧で囲みます。

```
ghci> :t fromIntegral
fromIntegral :: (Integral a, Num b) => a -> b
```

- lengthの型はなんか本のものと違いそう
- Foldable t =>
  - 意味：前提条件として、t は「中身を畳み込める（リストのように並べられる）箱」でなければならない。
  - => の左側は「型クラス制約（前提条件）」を表します。
  - t は任意の型が入る変数（型変数）です。
  - Foldable（フォルダブル）は、「要素を1つずつ順にたどることができる構造」という共通の性質（型クラス）です。
  - つまり、「普通のリスト [] だけでなく、Tree（木構造）や Map など、要素を順番に数えられる構造（t）なら何でもいいよ」という広い許可を出しています。

```
ghci> :t length
length :: Foldable t => t a -> Int
ghci> fromIntegral (length [1,2,3,4]) + 3.2
7.2
```

## 最後に


- 型クラスは抽象的なインターフェイス。
- 1つの型はいくつもの型クラスのインスタンスになることができるし、1つの型クラスはいくつもの型をインスタンスとして持てる
  - 例えばChar型をインスタンスとする型クラスはたくさんある。その中にEq, Ordがあり等知性比較とアルファベット順比較の両方ができる
- 型をある型クラスのインスタンスにするために、一旦別のインスタンスにする必要があることがある。
  - 例えばOrdクラスのインスタンスになるには、先にEqクラスのインスタンスになる必要がある。
  - → EqクラスのインスタンスであることはOrdクラスのインスタンスになるための必要条件である
  - 2つのものが順序づけられる＝それらが等しいかどうかも分かるはず

# Haskell学びメモ 20260707

- 関数合成：2つの関数を合成したものはまず1つの関数を呼び出し、それからもう1つの関数にその結果を渡して呼び出したものに等しい、という意味らしい
  - 数学だとこう：(f ・ g)(x) = f(g(x))
  - Haskellの関数合成もほとんど同じらしい
    - → 「.」関数を使って関数合成ができる
- fは引数として、gの返り値の型と同じ型の値を受け取らなければならない。
  - 合成された関数はgが受け取る型と同じ型の引数を受け取り、fから出力する型と同じ型の結果を返す

```
(.) :: (b -> c) -> (a -> b) -> a -> c
f . g = \x -> f (g x)
```

- ラムダ式が関数合成の結果に見える？関数合成で書き直すと

```
ghci> map (\x -> negate (abs x)) [5,-3,-6,7,-3,2,-19,24]
[-5,-3,-6,-7,-3,-2,-19,-24]
ghci> map (\xs -> negate (sum (tail xs))) [[1..5],[3..6],[1..7]]
[-14,-15,-27]
ghci> map (negate . sum . tail) [[1..5],[3..6],[1..7]
-- 関数合成で書き直し
ghci> map (negate . abs) [5,-3,-6,7,-3,2,-19,24]
[-5,-3,-6,-7,-3,-2,-19,-24]
ghci> map (negate . sum . tail) [[1..5],[3..6],[1..7]]
[-14,-15,-27]
```

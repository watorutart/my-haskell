# my-haskell

Haskellの学習記録と、学習メモから自動生成するクイズで振り返りを行うリポジトリ。

## 日々のクイズ生成のしかた

1. **学習メモを書く** — `study-memo/YYYYMMDD/` ディレクトリを作り、その日の学びを書く
   - `YYYYMMDD.md` … 学んだこと・ひっかかったポイントのメモ
   - `YYYYMMDD.hs` … 書いたコード
2. **Claude Codeで `/quiz-gen` を実行する** — それだけでOK
   - 当日のメモだけを読んで3〜10問の4択クイズデータ(`quiz/data/YYYYMMDD.js`)を生成
   - `quiz/data/manifest.js` に1行追記
   - ブラウザで `quiz/index.html` が自動で開く
3. **クイズを解く** — ダッシュボードの「最新のクイズを始める」から

メモが充実しているほど良い問題になります。「なぜそうなるのか」「どこでハマったか」を書いておくと、概念理解を問う問題が作られます。

## 振り返り(復習)のしかた

`quiz/index.html` をブラウザで開くだけ(AI不要・トークン消費ゼロ)。

- **復習モード** — 全期間の問題プールからランダムに5問/10問/20問を出題。選択肢の順序もシャッフルされる
- **過去のクイズ** — 日付一覧から選んでその日のクイズを解き直す

正誤履歴はブラウザのlocalStorageに自動記録されています(将来「間違えた問題だけ復習」などに拡張可能)。

## ディレクトリ構成

```
study-memo/YYYYMMDD/   日々の学習メモ(.md + .hs)。クイズ生成の唯一の入力
quiz/
  index.html           クイズアプリ(ダッシュボード+クイズ画面)。これを開く
  data/                クイズデータ。AIが生成するのはここだけ
  archive/             旧形式の自己完結HTML(参照用)
docs/quiz-system-spec.md  設計仕様書
.claude/skills/quiz-gen/  /quiz-gen スキル本体
```

## 注意

- `quiz/index.html` の見た目・演出はSNS動画撮影に使っているため変更しない
- 同じ日のクイズを作り直したいときは `/quiz-gen` 実行時にその旨を伝える(既存ファイルがあると上書き前に確認される)
